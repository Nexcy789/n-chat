# 调角色性格

这套框架的默认值是**一个人照着三个具体角色调出来的**，那三个人性格差别很大，
所以出厂的三套倍率也不一样。你拿到的不是「标准答案」，是一份参考样本。

换成你自己的角色之后，这些数字一定要重调。这一份讲怎么调。

---

## 1. 先看七维在管什么

每个角色有独立的一份情绪数值，0–1（恼火是 0–60 点），随时间和对话演化。
当前**最强的那一维**决定她这一轮的说话语气，最强值超过 55 才允许主动开口。

| 键 | 中文 | 涨什么、落什么 |
|---|---|---|
| `missing` | 想念 | 随时间涨，23:00–03:00 涨 1.6 倍；你每说一句 −25% |
| `jealousy` | 吃醋 | 缓慢发酵（基准的 5%）；你点名别人时跳一下；你说话 −10% |
| `warmth` | 暖意 | 你说甜话时涨；平时一直在落 |
| `worry` | 担心 | 凌晨 0–5 点且你一小时没动静时涨 |
| `boredom` | 闲 | 一直在涨，想念越高涨得越快 |
| `lust` | 亲密 | 只在你带那个方向的话题时涨，之后缓慢回落 |
| `annoyanceDebt` | 恼火 | 被冷落、被拒绝、被忽略时涨；随时间消，**0–60 点不是百分比** |

七维全部为 0 她就是个字面意义上的闷葫芦，七维全都拉满她就是个复读机。
调参的目标是让这七个数在一天里**此起彼伏地换着当第一**。

## 2. 出厂的三套倍率（参考样本）

在 `plugins/dsh-webchat/lib/mood-driver.mjs` 的 `PERSONA_RATES` 里：

| | 角色一 | 角色二 | 角色三 |
|---|---|---|---|
| 想念 | 1.0 | 1.15 | 0.9 |
| 吃醋 | 1.3 | 0.5 | 1.5 |
| 暖意增长 | 1.0 | 1.15 | 0.85 |
| 暖意冷却 | 1.0 | 0.75 | 1.2 |
| 担心 | 1.25 | 1.0 | 0.9 |
| 闲 | 1.1 | 0.85 | 1.15 |
| 消气 | 1.0 | 0.9 | 0.75 |
| 亲密 | 1.0 | 1.0 | 1.0 |

这三套对应的性格原型：

**角色一：外向、护人。** 吃醋吃得多但不会真拦，担心和闲涨得快。
这种角色在你熬夜的时候会一直冒泡，你要的是「有人在等你」的压迫感，不是耳根清净。

**角色二：慢热、稳。** 想念涨得快但吃醋极低，暖意来得快也退得慢。
这种角色不会因为你夸了别人就炸，但会在你三天不出现之后安静地说一句「你回来了」。

**角色三：敏感、易炸。** 吃醋最凶，想念最慢，气也最难消（消气 0.75 表示消得慢）。
这种角色一天里大部分时间在维持一个不太高兴的状态，你哄一次才好转一点。

**注意 0.9 这个想念倍率带来的副作用**：它会让她在「主动开口」这件事上长期排第三。
框架里为此专门加了轮空补偿（`missedBonusStep`），否则她一天 8 次一次都轮不到。
如果你把某个角色的想念倍率压到 0.5 以下，补偿也救不回来，得手动调
`talkativeness` 或者干脆别给她这么低的倍率。

## 3. 按性格调：怎么选数字

先写下你角色的性格，再对着下面找。每一条只说方向，具体数字自己试。

| 你的角色是…… | 调这里 | 方向 | 为什么 |
|---|---|---|---|
| 黏人、话多 | `missing` / `boredom` | ↑ 到 1.2~1.4 | 涨得快 → 更容易过 55 那道门槛 |
| 冷淡、不主动 | `missing` / `boredom` | ↓ 到 0.5~0.7 | 别让她变成闹钟 |
| 爱吃醋、占有欲强 | `jealousy` | ↑ 到 1.5~2.0 | 你点名别人时她跳得明显 |
| 大度、不吃醋 | `jealousy` | ↓ 到 0.3~0.5 | 低于 0.3 基本就感觉不到了 |
| 温柔、暖得久 | `warmthGain` ↑ / `warmthDecay` ↓ | 0.7~0.8 冷却 | 暖意退得慢，能维持半天 |
| 忽冷忽热 | `warmthDecay` | ↑ 到 1.3~1.5 | 暖意退得快，你得一直哄 |
| 操心、护人 | `worry` | ↑ 到 1.2~1.4 | 凌晨你没动静她会担心 |
| 脾气大、难哄 | `annoyanceDecay` | ↓ 到 0.6~0.8 | 60 点恼火要 75 分钟才消完 |
| 好哄、记吃不记打 | `annoyanceDecay` | ↑ 到 1.3~1.5 | 你哄一句她立刻恢复 |
| 主动粘人但不吵 | `missing` ↑ + `talkativeness` ↓ | | 情绪高但掷骰概率低，想说话但不抢话 |

**边界**：倍率会被夹在 `0.1` 到 `10` 之间，但落在 0.3 以下或 2.5 以上基本就没法用了——
要么那一维永远不动，要么它永远排第一、其余六维全被压死。

## 4. 两个容易忽略的配套项

情绪只决定「有多想说话」，**要不要真的开口**由协调器另外掷骰：

```yaml
talkativeness:
  role1: 0.7     # 每次有人说话，她被抽中接话的概率
  role2: 0.6
  role3: 0.8
```

这三个数不是随便填的，配置注释里写了它们的期望值：三个人合计期望 2.1 人接话，
约 2.4% 概率没人接。你把某个调到 0.95 她就会天天抢话，
调到 0.3 她在群里基本是背景板。

另一个是 `maxConsecutive`（默认 2），同一个人连说两条之后强制换人。
这个值调大到 3 以上，配合高 `talkativeness` 会出现「一个人刷屏一整晚」。

## 5. 改哪儿

**临时改**（不动代码）：写进你的 profile 覆盖配置。

```yaml
- id: dsh-webchat
  config:
    moodRates:
      role3: { jealousy: 2, annoyanceDecay: 0.6 }
```

这个覆盖的是**全局倍率**，会盖在出厂人设上（`{ ...全局, ...出厂人设, ...你的覆盖 }`）。

**永久改**（改出厂值）：直接改 `plugins/dsh-webchat/lib/mood-driver.mjs` 的
`PERSONA_RATES`。改完重启生效。

**面板只是显示，不能改**：群聊页面 → 设置 → 情绪那一栏，能看到每个人七维的当前值
和「现在最想他」这种标签。它是只读的，用来观察演化，不是调参入口。
要改只能改配置或改代码。

## 6. 调完怎么验证

别靠感觉。改完观察一天，或者跑一下模拟。

**看数值**：聊天页面 → 设置 → 情绪，能看到每个人七维当前值（只读）。
盯几分钟就能看出哪一维一直贴着满值（涨得太快，会垄断）或者一直贴着 0（根本不动）。

**看语气**：语气只有七种（黏人 / 吃醋 / 暖 / 担心 / 轻快 / 暧昧 / 闹别扭）。
如果你聊了一整天只见过两种语气，说明要么某一维垄断了，要么其余维度涨得太慢。

**看频率**：`data/webchat/webchat.log` 里搜 `· 自发`（这是主动开口的标记）
和 `问候窗口`，数一天各出现几次。默认目标是合计 4–8 次 / 天、间隔 1.5–2 小时。
差太远就调 `impulseThreshold` / `globalCooldownMin` / `maxPerDay` 这三个，
别去动七维——那是治标。

---

## 7. 一句话原则

**性格差异要落在「同一个事件引发不同反应」上，不是「数值大小不同」上。**

两个角色都想你、都吃醋，但一个把想念表达成撒娇、另一个表达成阴阳怪气——
这个差别应该在 `AGENTS.md` 里写，不是在倍率里调。倍率只决定
「多久想一次、想得多厉害」，怎么表现是人格文件的事。

调反了会出现怪现象：倍率调得很细，但两个人的语气仍然一模一样。
